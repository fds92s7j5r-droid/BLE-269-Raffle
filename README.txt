GITHUB PAGES
1. Create a new GitHub repository.
2. Upload index.html and the entire assets folder.
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and / (root), then Save.
6. Once GitHub provides the public URL, use that URL for the QR code on printed flyers.

IMPORTANT
The Pay with Zelle button uses the same destination encoded in the supplied official Zelle QR code.
If the payment destination ever changes, update both the Zelle QR image and the Zelle link in index.html.
